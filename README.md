## Featured Work

- **[ForgeIQ](https://github.com/mrbutler35-wq/ForgeIQ)** — flagship distribution-operations intelligence platform. The public demo uses synthetic ERP-style data; internal work is informed by SAP ERP workflows. The app supports operational KPI views, supplier/customer drill-downs, exception triage, and review tracking.
- **[Film Junky](https://github.com/mrbutler35-wq/Film-junky)** — academic IMDb sentiment-classification project: TF-IDF with Logistic Regression achieved 0.89 F1 and approximately 0.95–0.96 ROC-AUC across 47,331 reviews.
- **[Telecom Plan Classification](https://github.com/mrbutler35-wq/telecom-plan-recommendation-ml)** — academic Smart/Ultra recommendation classification; Random Forest achieved approximately 82% accuracy against a 75% project threshold.
- **[ForgeRAG](https://github.com/mrbutler35-wq/ForgeRAG)** — confidence-gated retrieval-augmented knowledge assistant with source attribution.
- **[Automated MLOps Pipeline](https://github.com/mrbutler35-wq/heart-disease)** — FastAPI inference, MLflow, DVC, GitHub Actions, Pytest, and Evidently monitoring. The repo documents 11 Pytest checks, an 80% CI accuracy floor, and a 25% drift-share threshold; these are project checks/configured gates, not commercial deployment metrics.
- **[House Price Prediction API](https://github.com/mrbutler35-wq/house_price_api)** — FastAPI inference service with Docker support, request validation, health checks, and tests.
