# Larry Butler Portfolio

A responsive, single-page professional portfolio hosted with GitHub Pages. The site presents Larry's progression from manufacturing, quality, and enterprise systems into AI/ML engineering, with selected projects and credentials.

## Preview locally

From the repository root on Windows, run:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>. Stop the server with `Ctrl+C`.

## Site files

- `index.html` — portfolio markup, styling, responsive navigation, and page content.
- `assets/larry-butler-headshot.png` — professional headshot used in the hero.

The repository is configured as a static GitHub Pages site. No build step or third-party frontend dependency is required.
