ForgeIQ — Operations Intelligence Platform

An operations intelligence platform that connects sales, purchasing, supplier, customer delivery, and project data to surface operational trends, anomalies, and areas requiring investigation.

ForgeIQ combines my 9+ years of manufacturing, engineering, quality, and industrial operations experience with Python, data engineering, analytics, machine learning, and application development.

Platform Architecture & Core Modules

  • Operations Intelligence Dashboard: Centralized operational metrics, KPIs, and real-time execution health monitoring.
  • Project Explorer: Deep-dive tracking into project timelines, cost metrics, and order fulfillment status.
  • Supplier Intelligence: Vendor delivery performance, purchasing velocity, and lead-time variability tracking.
  • Customer / Delivery Intelligence: On-time delivery performance, shipment velocity, and customer risk profiling.
  • Anomaly Review Center: Flagged transactional deviations, cost variances, and operational outliers requiring investigation.
  • Data-Quality Monitoring: Automated validation rules for data integrity, missing fields, unit mismatches, and schema health.
  • Explainable Operational Review Rules: Transparent, rule-based decision logic to guide plant managers and quality auditors.
  • Machine-Learning Experimentation: Predictive modeling experiments backed by time-based validation strategies.

Machine Learning Experimentation & Validation Findings

I experimented with predicting future customer delivery problems using supervised machine learning models. Initial results appeared promising, but stricter temporal validation revealed insufficient project-level future labeled data to justify production deployment. I intentionally chose not to deploy the model to production and identified delivery-level modeling as a future direction.

Pima Indians Diabetes Database

Pima Diabetes AI is an end-to-end machine learning application designed to assess diabetes risk using the Pima Indians Diabetes dataset. The project demonstrates a complete production-style AI workflow, including data preprocessing, feature engineering, experiment tracking with MLflow, model evaluation, Docker deployment, and an LLM-powered conversational interface that converts natural language into structured clinical features before generating contextual explanations.

Key Features

  • Automated preprocessing pipeline with KNN imputation for missing clinical values.
  • Feature scaling using configurable preprocessing pipelines.
  • Multiple machine learning experiments tracked with MLflow.
  • Automatic best-model selection based on evaluation metrics.
  • Model evaluation using Accuracy, Precision, Recall, F1 Score, and ROC-AUC.
  • Natural language patient input powered by an LLM.
  • Conversational AI interface that extracts structured patient data before prediction.
  • Human-readable AI explanations with medical disclaimers.
  • Docker support for reproducible deployment.
  • Modular project architecture designed for production-style workflows.
  • Automated testing for preprocessing, models, and interface components.
